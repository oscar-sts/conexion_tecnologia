== Installation ==

1. Colocar en falso la opción 'DISABLE_WP_CRON' que se encuentra en 'wp-config.php'
2. Ir a woocommerce -> Ajustes -> Integración -> intcomex Integration
3. Colocar las respectivas credenciales de prueba/producción
4. Ir a la pestaña intcomex Log y "Verificar Licencia"
5. Si es valida, Configurar los ajustes, y a guardar (En este momento iniciara a creación de productos y registro de precios e inventario)
